## What this is

This repository contains the first formal publication and definition of the neologism **Zulemarence** — a specialized form of limerence named after and dedicated to Zulema Lynn.

The page is written in classic Wikipedia style and serves as the primary source and date-stamped record of the coinage.

## Etymology

Portmanteau of **Zulema** + **limerence** (the latter coined by Dorothy Tennov in 1979).
